# Локальное сравнение копий

Первый компонент figmobil — прозрачное сравнение каталогов. Он читает выбранные локальные копии и показывает отличия; упаковка исходников, шифрование, передача через Figma и применение правок в этом компоненте отсутствуют.

## Запуск

Собранный файл находится в `dist/figmobil.exe`. Запустите его и откройте в браузере адрес, который появится в окне приложения. Введите полные пути локальной и входящей копий из Проводника. Если есть отдельная общая базовая копия, укажите её. Нажмите «Сравнить».

Существующий браузер используется как интерфейс. Wails, WebView2, Node, Go и плагины на целевом ноутбуке для запуска exe не устанавливаются. Go нужен только для сборки; Node — для проверок разработки. Приложение не создаёт службу, задачу расписания или автозапуск. Для остановки закройте окно приложения или нажмите Ctrl+C.

## Смысл результата

- Одинаковые файлы определяются по исходным байтам и учитываемому режиму, а не по времени изменения.
- Без базовой копии отличающиеся файлы требуют проверки: приложение не утверждает, что знает происхождение изменений.
- С базой различаются входящие изменения, сохранённые локальные изменения и конфликты обеих сторон.
- Отсутствующий входящий путь не является командой удаления.
- BOM, кодировка и окончания строк показываются как свойства. Перекодирование и нормализация не выполняются; текстовые эвристики не являются гарантией распознавания любой legacy encoding.

Общий бюджет на все выбранные копии: 5000 файлов и 32 МиБ; один файл — до 8 МиБ, глубина — до 128 уровней. Есть отдельный предел элементов каталогов и 90 секунд на запрос. Служебные каталоги и секретные имена исключаются с объяснением. Исключение по имени не является поиском всех возможных секретов. Символические ссылки и Windows reparse points не обходятся; соответствующие поддеревья остаются неизвестными, а отчёт помечается неполным. Ошибка чтения, изменение файла во время чтения или превышение предела не должны давать отчёт «всё одинаково».

Пути, исключённые имена, предупреждения и строки отчёта используют отдельный общий бюджет 8 МиБ на все копии. Он учитывается до накопления данных и консервативно ограничивает объём метаданных операции; это не замер heap процесса. Превышение возвращает `REPORT_SIZE_LIMIT` без частичного отчёта. Большой список исключений поэтому не обходит лимит через нулевой размер исходных файлов.

## Границы реализации

Выбранные каталоги и Git index не изменяются. Приложение не запускает Git, shell-команды, filters, hooks или код сравниваемого проекта. Для работы используется HTTP только на случайном порту `127.0.0.1`; запрос сравнения требует Origin текущего интерфейса и ключ текущего сеанса. HTTP не принимает команды записи файлов и не раздаёт каталог проекта.

На Windows принимаются обычные абсолютные пути дисков; UNC и пространства устройств отклоняются до чтения. Коллизии регистра и файл/каталог показываются как конфликты. Совпадение режима файлов не является проверкой Windows ACL.

Планирование опирается на снимки, полученные последовательным чтением. Приложение не блокирует редакторы и не гарантирует глобально атомарный снимок одновременно меняющегося дерева. Выявленное изменение при чтении приводит к ошибке. Для воспроизводимого сравнения приостановите изменения выбранных копий и запустите действие повторно.

## Разработка

```powershell
node scripts/project/verify.mjs
```

Команда запускает проверки обвязки, модель и контроллер UI, Go tests, go vet, проверку gofmt и сборку exe. Отчёт: `.artifacts/local-verification.json`. Контроллер тестируется на небольшой DOM-модели с управляемым транспортом: проверены запуск только по submit, блокировка дубля, восстановление поля базы, ошибки, поздний ответ после отмены, очистка устаревшего отчёта, фильтры и метаданные. Эти тесты не эмулируют браузерную раскладку, native validation и реальный переход клавишей Tab. Новые зависимости не нужны.

Go-тесты используют синтетические каталоги; наличие Git требуется только для отдельной изолированной проверки сохранности index/diff. Эти результаты не доказывают перенос или сборку исходного проекта на двух ноутбуках.

В предыдущей версии браузером проверен основной путь с тремя синтетическими копиями; сохранён `.artifacts/local-comparison.png`. Повторное подключение инструмента после переключения чата было отклонено политикой браузера; повторный доступ и обход не предпринимались. Новая сборка после исправлений базы/отмены проверена автоматическими тестами. Дополнительные ручные сценарии не отмечаются пройденными; полное браузерное end-to-end покрытие не заявляется.

Канонический контракт запроса и отчёта — Go-типы в `internal/compare`; сервер отвергает неизвестные поля запроса. UI и файловый слой разделены; DOM получает только метаданные, без содержимого исходников. Единственный прикладной endpoint — `POST /api/compare` с `baseRoot`, `localRoot`, `incomingRoot`.

## Незавершённая ручная UI-приёмка

В разрешённом браузере на синтетических копиях нужно выполнить следующие сценарии. Все строки ниже пока **не проверены вручную на текущей сборке**; результаты записываются отдельно от unit-тестов.

| Сценарий | Ожидаемый результат |
|---|---|
| Открытие и ожидание, ввод путей | Сравнение не начинается без кнопки; стартовый отчёт отсутствует |
| Tab/Shift+Tab, Space для базы, Enter для запуска | Все элементы доступны; поле базы видно и обязательно только при отмеченном флажке |
| Перезагрузка с восстановленным флажком базы | Видимость поля соответствует флажку, скрытая база не участвует в запросе |
| Работающее сравнение и повторное нажатие | Пути и запуск заблокированы; доступна отмена; второй запрос не создаётся |
| Отмена ещё работающего сравнения | Статус завершённой отмены, нет старого отчёта, фокус возвращён на запуск; повторная попытка ручная |
| Несуществующий путь и исправление | Понятная ошибка и её код; фокус у заголовка ошибки; после изменения пути старый результат очищен |
| Успех и пустой результат фильтра | Фокус у заголовка отчёта, поиск/фильтр работают без повторного сканирования, нулевой результат понятен |
| Раскрытие метаданных кнопкой/клавиатурой | Видимость и aria-expanded согласованы; путь и метаданные показаны текстом |
| Узкое окно и увеличенный масштаб | Поля, действия и горизонтальная прокрутка таблицы доступны без перекрытия |
