## Реализованный preview

`dist/figmobil.exe` — Go-приложение без сторонних зависимостей с встроенным HTML/CSS/JS. Открывает локальную службу на случайном порту `127.0.0.1`; адрес показан в видимом окне приложения. Интерфейс использует существующий браузер, запуск сравнения только по кнопке.

Сравниваются локальная, входящая и необязательная базовая копии. Отчёт различает совпадения, входящие/локальные изменения и конфликты, показывает метаданные EOL/BOM без перекодирования. Отсутствие файла не является удалением. Выбранные каталоги и Git index не изменяются; приложение не исполняет Git, hooks или код проекта.

Есть ограничения чтения, отмена, исключение служебных/секретных имён и ссылок, проверка Windows-путей, коллизий регистра и файл/каталог. Host, Origin и ключ текущего сеанса защищают endpoint сравнения. Инструкция и точные ограничения — [LOCAL-COMPONENT](LOCAL-COMPONENT.md).

При продолжении исправлены восстановление состояния базы при загрузке/pageshow и завершение отмены при позднем ответе. Для путей/предупреждений/строк отчёта добавлен общий бюджет 8 МиБ до накопления; превышение даёт `REPORT_SIZE_LIMIT` без частичного результата. Фокус при запуске передаётся кнопке отмены, после отмены — кнопке сравнения.
