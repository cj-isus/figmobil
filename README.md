# figmobil

Первый компонент — локальное сравнение копий проекта **без плагина**. Он показывает различия и конфликты между локальной, входящей и необязательной базовой копиями. Файлы и Git index только читаются.

Это ещё не готовый перенос: экспорт/импорт исходников, шифрование и работа с Figma не реализованы в текущем компоненте. Исходные требования ручного A ↔ B и сохранности Git diff остаются в [реестре](spec/project.json); работа выполняется по компонентам.

Оба поля текущего preview означают папки на этом компьютере. В целевом приложении на каждом ПК выбирается один свой проект, а входящая версия поступает из зашифрованного текста, скопированного с холста Figma. Основной сценарий — разработка с одной стороны, ручной merge с коллегами на другой и обратная отправка через Figma; [план транспорта](docs/TRANSPORT.md).

Статус — локальный preview: автоматические проверки и основной браузерный сценарий пройдены, полная ручная UI-приёмка открыта. Подробные результаты и следующий шаг — [STATE](docs/STATE.md).

## Запуск

Запустите `dist/figmobil.exe` и откройте в браузере адрес из окна приложения. Укажите полные пути копий проекта и нажмите «Сравнить». Для остановки закройте окно приложения или нажмите Ctrl+C.

На целевом ноутбуке используются exe и существующий браузер. Wails, WebView2, Node.js, Go и Figma-плагин для запуска этого компонента не устанавливаются. Работа на обоих целевых ноутбуках проверяется отдельно.

## Возможности

- Сравнение исходных байтов, размеров и метаданных; диагностика EOL/BOM без нормализации.
- Различение входящих и локальных правок при наличии общей базовой копии.
- Явные конфликты и отсутствие файла без автоматического удаления.
- Запуск по кнопке, отмена и защита от повторного запуска.
- Исключение служебных каталогов, секретных имён и ссылок; ограничения объёма чтения.
- Локальный интерфейс на `127.0.0.1` с ключом текущего сеанса и проверкой Origin/Host.

Подробности и ограничения — [локальный компонент](docs/LOCAL-COMPONENT.md).

## Разработка и проверки

Нужны уже доступные Go >=1.25 и Node.js >=22.13. Сторонних зависимостей нет.

```powershell
node scripts/project/verify.mjs
```

Команда выполняет тесты обвязки и UI, Go tests/vet/format и сборку Windows exe. Отчёт: `.artifacts/local-verification.json`. Тестирование сравнения не является доказательством шифрования или доставки между ноутбуками.

Отдельно реализован `internal/transferlimit`: чистая потокобезопасная политика порционной выдачи до 250 000 байт раз в 3 секунды (≤5 МБ/мин), 11 тестов. Она ещё не подключена к приложению или Figma; общий контроль всех окон/процессов и интерфейс ожидания относятся к будущей интеграции A-16.
